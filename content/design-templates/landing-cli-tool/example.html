Search a day of logs before your coffee cools.

sift reads plain, JSON and compressed logs in parallel, understands timestamps, and shows matches in context. One static binary, no daemon, no index to build.

What it does

Reads .gz and .zst

Decompresses in parallel, never to disk.

Knows time

--since / --until on any common timestamp format.

JSON fields

Query nested keys: .req.status >= 500.

Context

Lines before and after, grouped by request ID.

Histograms

--count-by 1m prints a bar chart in the terminal.

Pipes well

Plain text out by default, --json for scripts.

Read the docs, then grep less.
