# apps/desktop (od-desktop)

Tauri 2 shell. Runs od-server in-process and shows the od-ui it serves. Map: `../../docs/architecture.md`.
Paths below are relative to this folder.

## Owns
- Window, native menu, close and quit, updater, folder picker and save dialog, WKWebView quirks.
- `src/data_lock.rs`: `daemon.lock`, `daemon-app.url`, single instance. `src/close_guard.rs`: close and quit steps.
- `src/mac_quit.rs` (macOS `applicationShouldTerminate`), `src/js_dialogs.rs`, `src/web_process.rs`, `src/updater.rs`.
- The same binary also runs `mcp`, `daemon start` and the `od` client commands without a window.

## Entry points
- `src/main.rs:main`: command-line dispatch, then the Tauri builder (single-instance plugin first) and `.setup`.
- `src/main.rs:start_daemon`: `data_lock::acquire_waiting` → `Store::open` → bind `127.0.0.1:0`
  → `data_lock::record` → `od_server::router`. Then `ui_capability(origin)` and the window navigates there.
- `src/main.rs:on_run_event` → `hold_close` on close; `src/main.rs:before_exit` on exit.

## Adding a Tauri command (all five together)
1. `#[tauri::command]` fn and `generate_handler!` in `src/main.rs`.
2. `APP_COMMANDS` in `build.rs`.
3. `APP_COMMAND_PERMISSIONS` in `src/main.rs` (its length is part of the type).
4. The ACL test `src/main.rs::the_daemon_ui_may_call_the_app_commands`.
5. The generated `permissions/autogenerated/<cmd>.toml` (commit it). UI wrapper: `../../crates/od-ui/src/app/desktop.rs`.

## Invariants
1. One daemon per data dir. The app waits up to `APP_WAIT` only for its own quitting copy
   and refuses a CLI daemon at once (`src/data_lock.rs:acquire_waiting`).
   - `src/data_lock.rs::a_cli_daemon_is_refused_at_once`, `src/data_lock.rs::waits_for_the_app_only_and_only_so_long`
   - `src/data_lock.rs::takes_the_lock_once_the_quitting_app_lets_go`
2. The app records its URL in `daemon-app.url` with the lock (`src/data_lock.rs:record_app_url`);
   no data file has a bundle suffix (`.app`, `.bundle`).
   - `src/data_lock.rs::the_recorded_url_marks_the_holder_as_the_app`, `src/data_lock.rs::no_data_file_is_named_as_a_bundle`
3. `start_daemon` uses `acquire_waiting` and `record`; the single-instance plugin is registered first
   and only when `OD_DATA_DIR` is unset (`src/data_lock.rs:single_instance`).
   - `src/main.rs::a_launch_keeps_one_app_and_waits_for_the_last_to_let_go` (reads the source)
   - `src/data_lock.rs::single_instance_only_on_the_apps_own_folder`
4. Every close and quit path asks the page's leave guard (`hold_close` → `CloseGuard::step`):
   window close, macOS ⌘Q, menu and Dock, Windows File ▸ Quit. A page silent for 3 s does not block.
   - `src/main.rs::every_way_to_close_or_quit_asks_the_close_guard`, `src/main.rs::quit_on_windows_is_ours_so_it_asks_first`
   - `src/close_guard.rs::a_page_that_does_not_answer_does_not_keep_the_app_open`
5. Only a page really gone drops its "work not saved" flag.
   - `src/main.rs::only_a_page_really_gone_drops_its_word_of_work_not_saved`
6. Exit stops agents, deletes unsent draft images, then lets go of the lock (`before_exit`).
   - `src/main.rs::quitting_or_restarting_deletes_the_images_of_drafts_not_sent`
7. IPC is granted only to the daemon origin; the window navigates only there or to the splash;
   links open in the browser via `open_link` (http and https only).
   - `src/main.rs::navigation_stays_on_the_daemon_origin`, `src/main.rs::open_link_takes_web_addresses_only`
8. WebKit callbacks only queue a `ShellEvent`; they never call Tauri's dispatcher or wry `url()`.
   - `src/main.rs::webkit_callbacks_only_queue_shell_events`, `src/main.rs::the_shell_never_reads_an_address_through_wry`
9. Close actions run on a spawned thread, not inside the event-loop callback (`run_close_actions`). No test holds this.

## Traps
- Two tests running the Tauri mock event loop at once abort the test binary; take `one_mock_loop()` (#190).
- tao's app delegate has no `applicationShouldTerminate`; without `mac_quit` ⌘Q skips the guard (#190).
- A real close uses `destroy()`; `close()` asks again (#190).
- A second launch hit the lock and showed "an od daemon is already running"; single instance fixes it,
  only for the default data dir (#194).
- The app's previous copy may still hold the lock while it quits or updates: wait, do not fail (#194).
- Static source tests break on purpose when `start_daemon`, the plugin block or `hold_close` calls are renamed (#197).
- The App Management prompt comes from headless Chrome charged to Contour, not from a data file (#226; see od-render-cdp).
- The release app is ad-hoc signed; each update is a new signature, so macOS asks for folder access again (#260).
- The design iframe shares the web content process with the app UI; test the JS bridge on WebKit.
