# Contour (contour-design)

- When writing Rust, use the `rust-skills` skill (`.claude/skills/rust-skills`): read SKILL.md, look up the relevant rules/ sections.
- Behaviour spec: `docs/spec.md`. Settled decisions: `docs/decisions.md` (settled, do not re-ask).
- Original app source for comparison (read-only): `~/Documents/GitHub/open-design`.
- Check: `make check` (fmt + clippy -D warnings + test).
- Commits follow Conventional Commits; see CONTRIBUTING.md.

## Before you push (each item cost a CI round in Nov 2026)

- Commit messages: run `scripts/commitlint.sh origin/main HEAD` before the first push. Header ≤ 72; a body line that starts with `word:` is read as a footer (`footer-leading-blank`). Fixing a pushed message needs a new branch (`checkout -B <new> origin/main && merge --squash <old>`), as force-push is blocked.
- User-visible change: add a CHANGELOG.md line (CONTRIBUTING.md).
- Code under `cfg(target_os = …)`: CI runs clippy on Linux and Windows too; gate helpers with `cfg(any(target_os = "…", test))`.
- Dependency bumps: `make licenses` (needs `OPEN_DESIGN=~/Documents/GitHub/open-design`); `cargo deny check` for advisories.
- Tests: run only the e2e specs you touched locally (`crates/od-ui/e2e`); the full suite is CI's job. Wait on conditions (`waitFor`, `expect.poll`), never fixed sleeps; e2e runs 3 specs in parallel on CI.
- Fixing a bug: grep every site of the same pattern (same API, task kind, i18n string) and fix or list them all in the PR body; reviewers will find the siblings otherwise.

## Traps that recur

- Leptos 0.8: reading a disposed signal (`get`/`with`/`get_value`/`Callback::run`) after an `await` panics. Work the user asked for (send, delete, save) must finish after leaving the screen; guard only the UI part (`ScreenTasks::spawn_then`).
- Desktop (WKWebView): a design's iframe shares the web content process with the app UI, and the JS bridge must be tested on WebKit, not only Chromium. New Tauri command: `generate_handler!`, `build.rs` APP_COMMANDS, `APP_COMMAND_PERMISSIONS`, the ACL test, and the generated `permissions/autogenerated/*.toml`.
- axe ≥ 4.14 `label-content-name-mismatch`: an `aria-label` built from `"Open {0}"` fails in SOV languages; let the name come from the visible text.
